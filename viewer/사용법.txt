한국 지도 (오프라인 / 폐쇄망용)
=================================

[ 쓰는 법 ]
1. 이 폴더(korea-map) 통째로 PC에 둔다.
2. 폴더 안의  실행.bat  을 더블클릭한다.
3. 검은 창이 뜨고, 잠시 후 브라우저에 전국 지도가 자동으로 열린다.
   - 마우스 드래그: 이동
   - 마우스 휠: 확대 / 축소
4. 다 봤으면 브라우저를 닫고, 검은 창도 닫는다.

* 인터넷 필요 없음. 모든 데이터가 이 폴더 안에 있음.

[ 처음 실행 시 주의 ]
- 윈도우 방화벽 창이 뜨면 '액세스 허용'을 누른다. (localhost 전용이라 안전)
- 백신/보안 프로그램이 miniserve.exe 를 막으면, 회사 반입 승인된 파일이라고
  예외 처리해야 한다.

[ 폴더 구성 ]
- 실행.bat        : 실행 버튼
- index.html      : 지도 화면
- korea.pmtiles   : 지도 데이터 (전국, 약 483MB)
- miniserve.exe   : 지도를 띄워주는 작은 서버 프로그램 (설치 아님, 더블클릭 실행)
- lib/            : 지도 라이브러리 (MapLibre, PMTiles)

[ 데이터 출처 ]
- OpenStreetMap (© OpenStreetMap contributors)
- tiles.osm.kr 의 korea-latest-non-military.osm.pbf 기반
- 라이선스: ODbL / OpenMapTiles(CC-BY). 화면에 출처 표기 포함됨.

[ 데이터 갱신하려면 ]
- 외부 PC에서 새 .osm.pbf 를 받아 다시 변환해 korea.pmtiles 만 교체하면 됨.
